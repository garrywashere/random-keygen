# Specification

## Generator Requirements

-   Adjustable length (8, 16, 32, ...)
-   Presets for common configurations

## Features

-   Automatically copy generated keys to the clipboard
-   Manage a “recently generated keys” database:
    -   View
    -   Copy
    -   Delete entries
    -   Securely wipe
-   Store recently generated keys in a JSON file, along with their generation timestamps — useful if you change a password and forget to save it, reducing the risk of lockouts or lost credentials
